# Purchase Desk API

Purchase DeskのJSON API全10操作を説明します。ローカルで起動した検証用アプリに対するリファレンスです。

Qwenの生成結果をソースと照合し、追加補正後に68件のHTTP検査を実施しました。[生成と補正の記録](generation.md)を確認できます。

[呼出し手順](quickstart.md) · [認証](authentication.md) · [リファレンス](reference.md) · [OpenAPI](openapi.yaml)

アプリの起動と検証用ユーザーの登録は、[README](../../README.md)を参照してください。

対象ソースの識別情報と未確認事項は review.json に記録しています。公開中のAPIサービスや本番利用を保証するものではありません。

[提出・差戻し・再申請・承認の手順](workflow.md)
